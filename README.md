# Natural Language Projects

a repository hosting all of my natural language projects.

To start

- create venv
- install dependecies
- start venv

Project List:

1. [common-name-data](#/common-name-data) <br/>
   extracting common first name and surname data from a website and create a json. use web scrapping.
2. recommender
   use pytorch to create a recommender system based on movielens data that will recommend movies based on user history.
3. file-reader-assisstant
   use langchain with openapi and streamlit to create a RAG based file reader assisstant that can help answer questions based on provided file.
4. summarization
   a model that will summarize text articles.
